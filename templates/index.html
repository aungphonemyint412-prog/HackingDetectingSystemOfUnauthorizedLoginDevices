Hacking Detection System

Real-time detection of unauthorised login attempts using IP monitoring, device fingerprinting, behavioural analysis, and instant Gmail alerts.

Get Started Log In

System Capabilities

IP Address Monitoring

Detects logins from previously unseen IP addresses and flags them for review.

Device & Browser Detection

Parses user-agent strings to identify device type, browser family and OS.

Unusual Hour Detection

Flags logins occurring between midnight and 5 AM as potentially suspicious.

Brute-Force Detection

Raises an alert when multiple failed login attempts are detected in a short window.

Gmail Alert Notifications

Sends an HTML security alert email to the user whenever suspicious activity is detected.

Security Dashboard

Visualises login statistics, activity history, and security alerts in one place.
